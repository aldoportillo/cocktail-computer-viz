# Neat on the Rocks Computer Vision

This is a Computer Vision Solution for finding the name of a cocktail based off looks.

As a bartender, I can tell what a cocktail is 80% of the time by sight, 95% by scent and 100% by taste. If I can train a algorithm to get the 80% accuraccy that will be ideal.

This solution will be used on [Neat on the Rocks](https://www.neatonthe.rocks/) to enhance user experience. Our current paradigm consists of scanning a barcode or searching by cocktail name. We would like to replace that with simply taking a photo and looking through our data set for a matching cocktail.
